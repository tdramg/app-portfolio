## ✅ How to run locally

Requirements:
- Node.js 18 or newer
- npm (comes with Node)

Steps:
1. Download the repository ZIP or clone it from GitHub.
2. Open a terminal in the project root.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the dev server:
   ```bash
   npm run dev
   ```
5. Open the local URL shown in the terminal (for example `http://localhost:5173`).

The site will hot-reload on save.

---

## 🚀 How to build production files

1. Run:
   ```bash
   npm run build
   ```
2. The static production build will appear in the `dist/` folder.

You can deploy the contents of `dist/` to any static hosting provider (GitHub Pages, Netlify, Vercel, etc.).
